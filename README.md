# Supreme Magus / Arcane Simulation — Public Showcase

Static, public, sanitized landing page and gameplay footage for the Supreme Magus Minecraft Java 1.21.1 mod.

- `index.html` — responsive Portuguese landing page.
- `assets/demo.mp4` — OBS-edited, screen-verified gameplay excerpt.
- `assets/*.png` — screenshots from isolated QA.
- `STATUS.md` — dated and qualified test evidence and known limitations.

The mod's actual implementation repository is **private**. This site is deliberately distinct from the mod source. Never upload raw OBS recordings that include personal screens, world saves, cloud credentials or Minecraft account secrets.

This site is a static asset set that can be deployed via Cloudflare Pages, Workers static proxy or GitHub Pages.
